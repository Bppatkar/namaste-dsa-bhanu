📦 Array

Two Pointers

Generation 2 — Born from Array's problems
🗂 HashMap
Born from: Array + String
▶
Problem jo Array solve nahi kar pa raha tha: "Yeh number pehle aaya tha kya? Kitni baar aaya?" — Array mein dhundne ke liye O(n) lagta tha. Jab lakho elements hoon toh bahut slow.

Solution: Key-Value store banao jahan key ko directly O(1) mein dhundh lo — yahi HashMap hai. Frequency count O(n²) → O(n) ho gaya.
Patterns using HashMap
1
Frequency Count
Two Sum, contains duplicate, valid anagram, most frequent element
2
Prefix Sum + HashMap
Subarray sum = k — store running sum in map, check if (sum−k) already seen
3
Index Tracking
Longest consecutive sequence, 4Sum II, first unique character
🔍 Binary Search
Born from: Sorted Array
▶
Problem jo Array solve nahi kar pa raha tha: Sorted array mein koi number dhundho — O(n) lagta tha. 1 crore elements mein 1 crore steps.

Insight: Sorted hai toh middle dekho — agar target chota hai toh left mein hai, bada hai toh right mein. Har step mein aadha eliminate. O(n) → O(log n). 1 crore → sirf 20 steps!
Patterns using Binary Search
1
Classic Binary Search
Search sorted array, first/last position, search insert position
2
Search on Answer Space
Koko bananas, min days for bouquets — answer range pe binary search karo
3
Rotated / 2D Search
Search in rotated sorted array, find peak element, search 2D matrix
Generation 3 — Born from "last element yaad rakho" + memory problems
📚 Stack
Born from: "Last wala yaad rakhna tha"
▶
Problem jo Array solve nahi kar pa raha tha: Socho tum brackets check kar rahe ho — (()) — jab bhi ) aaye toh usse match karna hai last wale ( se, na pehle wale se. Array mein yeh track karna mushkil tha.

Real life example: Browser ka Back button — jo page last gaya tha, wahi pehle waapas aata hai. Yeh LIFO (Last In First Out) hai.

Aur ek example: "Mujhe aage wala pehle wala element chahiye jo current se bada ho" — yeh Monotonic Stack hai. Jab bhi naya element aaye, stack ke upar se chote elements nikaalte jao — jo bacha woh "next greater" hai.

Rule: Jab bhi "last wala yaad rakho aur compare karo" aaye — Stack use karo.
Patterns using Stack
1
Valid Parentheses / Bracket Matching
Valid parentheses, minimum remove to make valid, longest valid parentheses
2
Monotonic Stack
Next greater element, daily temperatures, largest rectangle in histogram, trapping rain water
3
Stack Simulation
Evaluate reverse polish notation, min stack, decode string, asteroid collision
Stack se kya paida hua:
🌲 Tree DFS — recursion internally Stack use karta hai
Jab tum recursion karte ho — function call hoti hai, uska state stack pe push hota hai, return pe pop hota hai. DFS yahi karta hai — isliye Tree DFS = "Stack ka use". Yahi connection hai.
🔗 Linked List
Born from: Array ka memory problem
▶
Problem jo Array solve nahi kar pa raha tha: Array mein beech mein element insert karo — saare elements ek jagah khisakne padte hain. 1 lakh elements hain toh 1 lakh shifts. Bahut slow.

Solution: Har element ek "node" mein store karo jisme data bhi ho aur next node ka address bhi. Memory mein kahin bhi store karo — pointers se jodo. Ab insert/delete = sirf pointers badlo. O(n) insert → O(1) ho gaya.
Patterns inside Linked List
1
Fast & Slow Pointers
Cycle detection, find middle of list, happy number, reorder list
2
Reverse Linked List
Reverse full list, reverse in groups of k, reverse between positions
3
Two Pointers on LL
Merge two sorted lists, palindrome linked list, remove nth from end
Linked List se kya paida hua:
🌲 Binary Tree — node ke 2 children pointers
🚃 Queue — nodes ko line mein jodte hain
Generation 4 — Born from Linked List
🌲 Binary Tree + BST
Born from: Linked List (2 children pointers)
▶
Problem jo Linked List solve nahi kar pa raha tha: LL mein search O(n) tha — ek hi direction mein ja sakte the. Agar ek node ke 2 pointers hoon — left aur right — toh? Hierarchy represent ho sakti hai. Aur ek rule add karo: left < root < right → BST! Ab search O(log n).
Patterns inside Binary Tree / BST
1
DFS — Recursion / Stack
Pre/In/Post order traversal, path sum, max depth, diameter, symmetric tree, LCA
2
BFS — Level Order using Queue
Level order traversal, zigzag, right side view, average of levels
3
BST Specific Patterns
Validate BST, kth smallest, insert/delete — inorder = sorted list
4
Tree Construction
Build tree from preorder+inorder, serialize & deserialize binary tree
Binary Tree se kya paida hua:
🕸 Graph — tree mein cycles allow karo
⛺ Heap / Priority Queue — complete binary tree with ordering rule
🚃 Queue
Born from: BFS ki zaroorat
▶
Problem: Tree/Graph mein level-by-level explore karna tha — jo pehle aaya usse pehle process karo (FIFO). Stack LIFO tha — kaam nahi aaya. Queue = FIFO — BFS ke liye perfect.
Patterns using Queue
1
BFS — Breadth First Search
Shortest path, level order, word ladder, rotten oranges, 01 matrix
2
Monotonic Deque
Sliding window maximum — double-ended queue, O(n) solution
Generation 5 — Born from Binary Tree
🕸 Graph
Born from: Tree (cycles allowed + multiple parents)
▶
Problem jo Tree solve nahi kar pa raha tha: Tree mein ek node ka sirf ek parent hota hai, cycles nahi hoti. Real world mein? Cities mein roads bidirectional hoti hain, ek city ke multiple roads ho sakte hain. Tree itna rigid tha. Graph = Tree with cycles + multiple connections allowed.
Patterns inside Graph
1
BFS on Graph
Shortest path unweighted, number of islands, word ladder, clone graph
2
DFS on Graph
Cycle detection, connected components, flood fill, path existence
3
Topological Sort
Course schedule, task dependency — kaam karne ka order nikalo
4
Union Find (Disjoint Set)
Connected components, redundant connection, number of provinces
⛺ Heap / Priority Queue
Born from: Binary Tree (with min/max rule)
▶
Problem: "Sabse chota/bada element baar baar chahiye — insert bhi hota rahe." Sorted array se nikalna O(1) tha lekin insert O(n). Heap ek complete binary tree hai jisme parent hamesha child se chota (min-heap) ya bada (max-heap) hota hai. Insert O(log n) + Get min/max O(1).
Patterns using Heap
1
Top K Elements
Kth largest, top k frequent, k closest points — min/max heap
2
Two Heaps
Find median from data stream — max heap + min heap simultaneously
3
K-way Merge
Merge k sorted lists/arrays, kth smallest in sorted matrix
Generation 6 — The Final Boss
🧠 Dynamic Programming
Born from: Recursion + Overlapping subproblems
▶
Problem jo Recursion solve nahi kar pa raha tha: Fibonacci(40) recursion se chalao — 1 billion se zyada calculations hoti hain! Kyunki same subproblems baar baar solve ho rahe hain.

DP ka janam: Ek baar solve karo, result yaad rakho (memoize karo). Dobara wahi problem aaye toh stored answer return karo. O(2ⁿ) → O(n). Isi liye DP = Recursion + Memory.

Color red kyun: Yeh sabse advanced hai — sabse zyada practice maangta hai. Har topic se kuch na kuch DP mein aata hai.
Patterns inside DP
1
1D DP
Climbing stairs, house robber, jump game, coin change, decode ways
2
2D DP — Grid / String
Unique paths, min path sum, LCS, edit distance, longest palindromic subsequence
3
Knapsack (0/1 + Unbounded)
Subset sum, partition equal subset, coin change 2, target sum
4
Interval DP
Burst balloons, palindrome partitioning, matrix chain multiplication
Exact order to follow:
Array → String → HashMap → Binary Search → Stack → Linked List → Queue → Binary Tree + BST → Graph → Heap → Dynamic Programming
