Problem Pattern Recognition Guide

4 steps mein koi bhi problem ka pattern identify karo. Ye guide dimag mein store karo — interview mein yahi kaam aata hai. Har question ke modal mein ye guide highlighted milegi.

Step 1

Start with the Constraints

Input size dekho — yeh batata hai kaunsa approach allowed hai aur kaunsa TLE dega.

n ≤ 20 Small Input Brute Force OK
  • Brute force acceptable hai
  • Backtracking + recursive enumeration
  • O(2n) ya O(n!) OK hai
  • Saare combinations explore karo
Use: Backtracking, DFS, Recursion
103 ≤ n ≤ 106 Moderate Input Brute Force TLE
  • Brute force bahut slow hoga
  • O(n) ya O(n log n) chahiye
  • Two Pointers, Sliding Window, DP
  • HashMap, Heap, Binary Search
Use: 2P, SW, DP, HashMap, Heap, BS
n ≥ 107 Very Large Input Even O(n) slow
  • O(n) bhi bahut slow hoga
  • O(log n) ya O(1) chahiye
  • Binary Search, Math tricks
  • Precomputed formulas
Use: Binary Search, Math, Prefix Sum
Step 2

Decode the Input Format

Input ka structure dekho — yeh seedha pattern suggest karta hai.

Tree
Trees (Binary / BST)
DFS: all paths, preorder/inorder
BFS: level-order, shortest path
BST property: O(log n) search
Graph
Graphs (Nodes+Edges)
BFS: shortest path
DFS: connected components
Union-Find: connectivity
Grid
2D Grids / Matrices
DFS/BFS: "islands" problems
Union-Find: connected regions
DP: pathfinding, counting
Sort
Sorted Arrays
Binary Search: O(log n) lookup
Two Pointers: pairs/triplets
Greedy: optimal selection
Str
Strings
Two Pointers: palindrome
Sliding Window: substring
Trie: prefix/word problems
List
Linked Lists
Fast/Slow: cycle detection
Dummy node: cleaner code
Reverse: in-place modification
Step 3

Understand the Output Type

Answer kaisa chahiye — yeh bhi pattern narrow karta hai.

List
List of Lists
(paths, subsets, combos)
Backtracking / DFS
Recursion: Take, Not Take
Val
Single Value
(max profit, min cost, #ways)
Dynamic Programming
Greedy for quick optimal
Mod
Modified Structure
(in-place edits)
Two Pointers
Space-efficient O(1)
Ord
Ordered Output
(sorted tasks, ranked)
Heap / Topological Sort
Custom sorting
